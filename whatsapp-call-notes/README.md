# 🎙️ About Callory

**Callory** is a Chrome extension that records audio from an active
**WhatsApp Web call** and saves the recording locally as a `.webm` file.

The current version focuses on reliable browser-based audio capture.

But Callory is designed to become more than a recorder.

The long-term goal is to turn conversations into something you can
**record, transcribe, understand, search, and remember.**
